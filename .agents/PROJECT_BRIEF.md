# PROJECT_BRIEF — 어르신 키오스크 도우미 AI

## 목표
카메라로 키오스크 화면을 인식하고, 스피치+메신저 채팅으로 어르신 눈높이 설명. 음성 요청 이해 후 단계 안내.

## 사용자 스토리
1. 어르신이 "햄버거 주문하고 싶어" 말함 → STT → 의도 파악 → 첫 화면 설명 시작
2. 카메라로 키오스크 촬영 → OCR "1. 매장/포장 선택" 인식 → TTS "왼쪽 매장 버튼을 눌러주세요" + 메신저 버블 표시
3. 막히면 "처음으로 돌아가줘" → 이전 단계로 복귀 안내

## 비기능
- Python 3.10+, FastAPI, uvicorn 3000포트
- HTML 단일 파일 우선, 외부 빌드 불필요
- 오프라인 예비테스트 가능하도록 목업 모드 (`MOCK_VISION=1`)
- 개인정보: 촬영 이미지는 서버에 저장 금지, 메모리 처리만
