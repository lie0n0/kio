# 어르신용 사용 설명서 (큰 글자로 읽어주세요)

> 화면 위 글자가 작으면 손가락으로 화면을 벌려 크게 하세요.
> 어려우면 언제든 **직원 호출** 버튼을 누르세요.

---

## 1단계. 카메라 켜기 📷

1. 초록색 **카메라 켜기** 버튼을 누르세요.
2. "카메라 허용"이 나오면 **허용**을 누르세요.
3. 내 얼굴이 나오면 키오스크 화면을 비추세요.

> 안 되면: 주소창 왼쪽 자물쇠 → 카메라 **허용**으로 바꾸세요.

## 2단계. 촬영 · 설명 듣기 📸

1. 초록색 **촬영 · 설명 듣기** 버튼을 누르세요.
2. "사진을 찍었어요"가 나오면 잠시 기다리세요.
3. 기계가 말로 알려줍니다. (예: "왼쪽 매장 버튼을 눌러주세요")

> 흔들리면: 키오스크 정면에서 한 뼘 거리로 다시 찍으세요.

## 3단계. 듣기 🔊

1. 못 들으셨나요? **다시 듣기** 버튼을 누르세요.
2. 소리가 작으면 휴대폰 옆면 버튼으로 키우세요.
3. 글도 함께 나옵니다. 천천히 읽어보세요.

## 4단계. 말하기 🎤

1. **말로 물어보기** 버튼을 누르세요.
2. "듣고 있어요"가 나오면 천천히 말씀하세요.
   - "처음으로 돌아가줘"
   - "결제 방법 알려줘"
   - "다시 천천히 말해줘"
3. 말이 끝나면 자동으로 답해줍니다.

> 말이 안 통하면: 키보드로 직접 적을 수 있어요.
> 그래도 어려우면: **직원 호출** 🔔 버튼을 누르세요. 곧 도와드리러 옵니다.

---

## 어려울 때 — 한 줄 정리

| 상황 | 누를 버튼 |
|------|-----------|
| 처음부터 하고 싶어요 | 🏠 처음으로 |
| 사람을 부르고 싶어요 | 🔔 직원 호출 |
| 인터넷이 끊겼어요 | 잠시 기다렸다가 촬영 버튼 다시 누르기 |
| 사진이 흐려요 | 빛 반사 피해서 정면으로 다시 촬영 |

천천히 하셔도 됩니다. 한 번에 하나씩만 하세요. 😊
